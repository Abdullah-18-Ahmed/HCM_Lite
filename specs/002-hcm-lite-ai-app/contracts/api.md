# Contract: FastAPI Backend API

**App**: `hcm_lite.api.main:app` • **Base path**: `/api/v1` • **Docs**: `/docs` (OpenAPI,
generated by FastAPI from the Pydantic models). Version 1.0.0; breaking changes need `/api/v2`.

Every route is a thin adapter: validate input with Pydantic, resolve the user from the token,
call **one service method** (contracts/services.md), and return its result. Routes contain no SQL,
ORM, permission or business logic (constitution Art. IX.1.4, XIV).

## Authentication

- `POST /api/v1/auth/token`: form fields `username`, `password` (OAuth2 password flow). Calls
  `AuthService.authenticate` (same lockout and audit as Chainlit, `channel="api"`).
  200 `{access_token, token_type:"bearer", expires_in}`; 401 a generic `invalid_credentials`
  (also for locked or inactive accounts, never revealing which).
- All other routes need `Authorization: Bearer <JWT>` (HS256, `API_JWT_SECRET`, claims
  `sub, iat, exp, jti`, lifetime `API_TOKEN_MINUTES`, default 60). The dependency
  `current_user` verifies the token, then **reloads the user from the DB** (`AuthService.load_user`).
  Missing, invalid or expired token → 401; inactive user → 401.
- `POST /api/v1/auth/logout`: adds `jti` to an in-memory deny-list until `exp`; audit `logout`.
  204.

## Endpoints

| Method | Path | Service call | Response body |
|--------|------|--------------|---------------|
| GET | `/me` | `AuthService.load_user` | `{user_id, username, role, display_name, department}` |
| GET | `/dashboard` | `DashboardService.for_user` | `DashboardData` |
| GET | `/me/profile` | `MetricsService.my_profile` | `ToolResult[ProfileResult]` |
| GET | `/metrics/headcount?department=` | `MetricsService.headcount` | `ToolResult[HeadcountResult]` |
| GET | `/metrics/attendance?period=&start_date=&end_date=&department=` | `MetricsService.attendance_summary` | `ToolResult[AttendanceSummary]` |
| GET | `/metrics/late-comers?period=&…` | `MetricsService.late_comers` | `ToolResult[LateComersResult]` |
| GET | `/metrics/leave?period=&status=&department=` | `MetricsService.leave_summary` | `ToolResult[LeaveSummary]` |
| GET | `/metrics/payroll?period=&department=` | `MetricsService.payroll_summary` | `ToolResult[PayrollSummary]` |
| GET | `/employees?name=&department=&job_title=&status=` | `MetricsService.search_employees` | `ToolResult[EmployeeSearchResult]` |
| GET | `/leave/balance?leave_type=` | `LeaveService.my_balance` | `ToolResult[LeaveBalanceResult]` |
| GET | `/leave/requests?limit=` | `LeaveService.my_requests` | `ToolResult[LeaveRequestList]` |
| POST | `/policies/search` `{query, doc_type?}` | `PolicyService.search` | `ToolResult[PolicySearchResult]` |
| POST | `/assistant/conversations` | create `ApiConversation` | 201 `{conversation_id}` |
| POST | `/assistant/conversations/{cid}/messages` `{message}` | `runner.run_turn` | `{reply, citations[], ready_draft: LeaveDraft\|null, error_category\|null}` |
| POST | `/assistant/conversations/{cid}/drafts/{draft_id}/confirm` | `LeaveService.submit` | 201 `{reference, status:"pending"}` (200 with the same body if already submitted) |
| DELETE | `/assistant/conversations/{cid}/drafts/{draft_id}` | discard the draft | 204 |
| GET | `/health` (no auth) | DB `SELECT 1` + vector store count | `{status, database, vector_index, demo_mode}` |

There is **no** endpoint that approves, rejects or cancels leave, and none that edits HR records.

## HTTP mapping of service results

| Condition | Status | Body |
|-----------|--------|------|
| `ToolResult.ok = true` | 200 | the envelope |
| `ToolResult.error.code = no_data` | 200 | the envelope (`ok=false`); it's not an error for the client |
| `access_denied` / `AccessDenied` | 403 | `{error:{code:"access_denied", message}}` + audit |
| `invalid_input` / Pydantic validation | 422 | `{error:{code:"invalid_input", message, field}}` |
| `NotFound` (conversation/draft of another user, unknown id) | 404 | `{error:{code:"not_found"}}` |
| `DatabaseError` | 503 | `{error:{code:"database_unavailable"}}` |
| `RetrievalError` / model failures | 503 | `{error:{code:<runner category>}}` |
| Unhandled | 500 | `{error:{code:"internal_error", correlation_id}}`; no traceback |

## Cross-cutting

- Conversations and drafts are owned by `user_id`. Another user's `cid` → 404.
- A request ID header `X-Correlation-ID` (generated if absent) is echoed back and written to
  logs and audit.
- CORS is disabled by default (no browser frontend consumes the API yet); `API_CORS_ORIGINS` can
  enable it.
- Run: `uvicorn hcm_lite.api.main:app --port 8001` (Chainlit uses 8000).
